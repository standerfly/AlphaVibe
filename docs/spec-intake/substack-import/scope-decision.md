# Scope Decision: Substack 文章自動匯入（011）

**Feature Slug:** substack-import
**Last Updated:** 2026-11-19（追加決定後修訂）

## MVP In Scope

1. 以 RSS 為唯一來源，輪詢設定檔中的追蹤作者（初始：FOMO研究院電子報、大叔美股筆記）。（SRC-002 決定2、3、追蹤來源）
2. 獨立 `substack.db` 儲存文章；去重鍵 guid／URL；不動 `articles.db`。（決定4；SRC-001）
3. 首次執行只收首次執行日前 14 天內文章。（決定5）
4. 排程：每日 22:00 一次；011 專屬獨立鎖。05:00～18:00 時窗只約束會消耗 AI agent token 的工作，RSS 抓取、即時取得、22:00 排程不受限。（決定6、10；「追加決定」第4題）
5. 免費文章存全文；付費文章存預覽並標記「僅預覽」；判斷規則為三類（P 預覽／F 全文／N 非文字），無法確定者一律存為「僅預覽」，不得以文章長度判斷。（決定7；Q-103）
6. 圖片下載存本機、不自動分析；內文保留圖位標記（含圖說／alt）。即時取得時圖片同步下載，失敗者由排程補下載。（決定8；「追加決定」第5題）
6b. **手動轉寫（限手動、少量）**：第一版能對少數幾篇文章手動跑一次圖片轉寫以驗證流程與功能；不排程、須 PO 當下親自確認、不改 010 既有行為與 `articles.db`；試跑對象＝F 類、較近期文章每位作者 1～3 篇（Q-115）；實作路徑規格階段判定（Q-122）。（「追加決定」第2題）
7. 011 文章預設不進 010 排程轉寫流水線，附測試要求；排程不呼叫模型。（SRC-001 010補充）
7b. 會消耗 AI agent token 的排程之間（含 010 的 23:40）間隔過短時，系統提醒 PO 修改（健檢／通知，不自動改排程）；數值待定（Q-117）。（「追加決定」第3題）
8. Telegram 通知含作者＋標題；日誌／錯誤訊息不含標題；外洩掃描與無洩漏測試。（決定9；SRC-001）
9. 健檢／通知回報剩餘硬碟空間與 `substack.db`／圖片目錄占用量，不設閾值。（決定11）
10. 即時取得：Mac Claude Code 與 claude.ai 連接器兩入口；連接器入口為台美兩邊都有的通用寫入工具（不收網址參數、只寫 `substack.db`、不進唯讀白名單、同作者最小間隔守衛）；守門數字以合併當下 `function/alphavibe` 實際值為準：011 為台股／美股各 +1、唯讀不變（撰寫時 2026-11-19 實測基準：台股 50、美股 10、唯讀 31，僅為背景資訊）。（即時取得）
11. `search_articles`／`get_article` 同時查兩庫，結果標示來源（出版名稱）與「僅預覽」。（決定4、市場標籤）
12. 追蹤清單設定檔，由 Claude 在對話中新增／停用作者。（決定3）
13. 403／429 與異常：停手、告警、不重試轟炸；條件請求（ETag）、逾時、通用 User-Agent、遵守 robots.txt。（SRC-001；SRC-003）
14. PO 親自確認的範圍＝登入、鑰匙圈、消耗用量，以及安裝排程；RSS 輪詢不逐次確認（Q-101 已答）。（SRC-001；「追加決定」第1題）
14b. 來源可信度標示：引用 Substack 作者意見須標明來源與「僅預覽」。（SRC-001 Components 3）
14c. 新增寫入工具不得破壞 010「文章通道唯讀」守門，須另證；即時取得須有逾時內回報進度或分段的行為（Q-118）。（SRC-004；「追加決定」第5題）
15. 舊庫唯讀相容、010 既有行為與守門測試不得改變（僅 parity 測試對新工具例外）。（SRC-001；即時取得）

## Out Of Scope

- Gmail 通知信取文、通知信連結跟隨。（決定2）
- 登入 Substack、使用任何 cookie、私人 feed token、繞付費牆、抓付費全文。（SRC-001）
- 抓取單篇網頁（即時取得也只認 RSS）。（即時取得）
- 修改、遷移或共用 010 的 `articles.db`。（決定4）
- 排程階段呼叫任何模型、消耗訂閱額度、排程化／自動圖片分析（手動少量轉寫除外，見 MVP 6b）。（SRC-001 010補充；決定8；「追加決定」第2題）
- 自動轉發、公開、散布文章內容。（SRC-001）
- 市場（台／美）標籤。（Q-015，第一版不做）
- 硬碟空間閾值判斷與異常告警。（Q-011）
- 歷史全量回補（RSS 只有最近 20 篇）。（SRC-003 §2；決定5）
- 網址參數的抓取工具。（即時取得「不接受網址」）

## Deferred Or Later

- 市場（台／美）標籤與依市場隔離搜尋（Q-015、Q-113）。
- 文章被作者修改後的更新偵測（Q-109）。
- **排程化（自動）圖片轉寫**：PO 只要求第一版手動少量轉寫（MVP 6b）；排程化轉寫若須改動 010 流水線或新增消耗 token 的排程，屬後續獨立包（受 Q-117 間隔提醒要求約束）。
- feed 超過 20 篇漏文偵測（Q-110）。
- 圖片保留期限與清理（Q-114）。
