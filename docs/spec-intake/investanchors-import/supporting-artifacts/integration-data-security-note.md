# Integration, Data & Security Note: 定錨產業筆記文章自動匯入

**Feature Slug:** investanchors-import

## 整合（第三方網站）

- 對象：investanchors.com，登入後頁面 `/user/vip_contents/investanchors_index`；清單含分類頁籤（總覽／週報／產業／台股／美股／總經／最愛）、每列標題＋日期＋留言數，已讀為細體、未讀為粗體（SRC-002）。
- 逾時／重試：單頁逾時即計一次失敗；連續失敗達門檻（plan 階段定）即中止並退避，不反覆重試。
- 速率：每批篇數上限、批次間隔隨機化；上限數值於 plan 決定（比照機票 20 筆/小時的保守思路）。
- 結構假設：文章有穩定網址/ID；內文為文字段落＋表格圖片（SRC-003）。**需在 Mac 實測確認。**
- 副作用風險：開啟文章可能改變「已讀」狀態（Q-004）。

## 資料

- 欄位：文章ID／網址、標題、發布日期、分類標籤（可多個）、全文、圖片檔路徑、抓取時間、狀態。
- 儲存：獨立資料庫（建議，Q-005）；全文需可 FTS 檢索；圖片存本機檔案並以文章關聯。
- 生命週期：只增不刪；內容更新（網站改文）是否覆寫列為 plan 決定。
- 台股/美股獨立：以標籤區分，台/美連接器各自只能查自己的分類（Q-005）。

## 安全與隱私

- 帳密只放 macOS 鑰匙圈（新增項目名稱，如 `stnd-investanchors`）；寫入指令 `-a` 後接固定名稱、`-w` 後不接值；排查時**禁止** `dump-keychain`、`-w`、`-g`（009 教訓）。
- 登入狀態檔（cookie）視同密碼：不進 repo、放 gitignore 目錄。
- 內容為付費會員專屬：僅 PO 個人使用、不對外分享；資料只經已有驗證的路徑讀取（Q-008）。
- 日誌不得輸出帳密、cookie、全文。

## 批次與部分失敗

- 單篇失敗不影響他篇；失敗清單可重跑；回補可中斷續跑；已存文章不因後續失敗被刪。
