# AlphaVibe — 主軸重塑：基本面選股與交易紀錄 (SRC-009)

> 來源：2026-07-07 PO（Stander）需求釐清對話。PO 原提議「開新專案」，
> 經兩輪討論定案為**重塑 AlphaVibe 主軸**（維持單一投資產品，符合 Q-022）。
> 本文件為原始需求素材；決策對應 clarification-log Q-028~Q-032；
> FR 編號為**候選編號**，接續 SRC-002 的 FR-018。

## 1. PO 原話（需求陳述）

「我的目的是可以從基本面選擇我想要的股票並評估買賣價格，且可以持續維護，
並變成資料庫讓後續都可以繼續使用。

我目前的資料來源有 LINE 的訊息、網誌與網頁資料、網頁資訊、YouTube 等。

我想跟 AI AGENT 聊這些資訊並有儀表板可以圖像化輔助我觀察，然後 AI AGENT
幫我歸類好訊息。最後我可以記錄我的預計與實際進出場位置。

AI AGENT 就是用目前的 Claude 為主（聊天思考）與 CLINE 輔助
（簡易不難的工作，例如爬蟲）。」

MVP 優先序的補充口述：「我目前會是藉由（資訊歸檔的）討論找出目標股，
然後再討論估值——也就是先基本面好、再討論估值，然後才會決定要不要買入賣出。」

## 3. 候選功能需求（接續 FR-018）

- FR-019 名單驅動選股：與 AI 討論歸檔資訊時浮現的標的，AI 即時補上
  基本面數據（FinMind/AV 個股級，沿用 FR-008）協助評估「基本面好不好」
- FR-020 哲學驅動候選：AI 依 Layer 1 投資哲學模組（如低 PER、高殖利率）
  結合數據與歸檔資訊，主動提出候選標的
- FR-021 估值討論：對基本面已認可的標的，與 AI 討論買賣價格區間；
  結論（目標買價/賣價與理由）寫入 Layer 2（`entry_condition`、
  `valuation_metric` 欄位為既有 schema）
- FR-022 交易紀錄：記錄預計進出場（價位、時間、理由）與實際進出場，
  可對照檢視（後行階段，見 Q-029）
- FR-023 YouTube 來源：納入資料來源清單（處理方式見 OQ-1）
- FR-024 總覽名單儀表板：觀察名單一覽——基本面狀態、距離目標買價、
  近期相關訊息量（優先序第一，Q-031）
- FR-025 資訊流時間軸：歸類後訊息按時間／標的排列檢視（優先序第二，Q-031）
