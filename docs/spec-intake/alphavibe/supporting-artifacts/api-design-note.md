# API Design Note: AlphaVibe（產品層介面盤點）

**Last Updated:** 2026-07-07

> 定位：滿足前後端分離原則（SRC-001 §8）所需的**產品層**介面盤點——
> 說明系統對外／對前端需要提供哪些能力面。詳細 API contract
> （路由、schema、錯誤碼）由 Spec Kit 階段的 speckit-plan 產出
> （readiness-checks GAP-001）。

## 介面能力面（依功能分組）

| 能力面 | 說明 | 對應 FR |
|--------|------|---------|
| 資料輸入 | 貼入文字（含來源 tag）、提交 URL 觸發爬取、上傳圖片 | FR-001、FR-009、FR-010 |
| AI 對話輸入 | 送出對話訊息、接收歸檔提議、回覆確認／修改／略過 | FR-015~FR-017 |
| 待確認佇列 | 列出待人工確認片段（格式不符／立場抽取），確認或退回 | FR-003、場景 3 |
| 知識庫查詢 | Layer 2 立場查詢與人工修正、Layer 3 全文檢索、Layer 1 模組清單 | FR-003、FR-014、FR-016 |
| 報告 | 取得當日結構化報告、來源回溯連結解析 | FR-004、FR-006、FR-007 |
| 自選股 | watchlist 新增／刪除／檢視 | FR-005 |
| 系統狀態 | 排程執行結果、外部 API 抓取狀態（供錯誤標記呈現） | §9 錯誤矩陣 |

## 約束

- 單人使用（v1），無認證授權需求；多用戶時再議（scope-decision）
- 介面回應不要求即時；長工作（爬取、Vision 解析）採非同步（SRC-001 §1）
