## 1. EP461：成交量四步驟（轉述）

1. **位階**：只在關鍵價位（支撐、壓力）看量；盤整區間裡的量當雜訊，不用每天看。
2. **量有多大**：先比前 5 日均量，再比月均量；創半年、一年新高量意義更大。他自己的篩選標準是 2 倍、3 倍甚至 5 倍，超過五成只是最低門檻。
3. **當天收在哪裡**：收在最高附近是明確的多頭訊號，留長上影線可能是假突破；跌破時收在最低附近是明確的空頭訊號。
4. **之後 3 到 5 天**：量要縮，而且價格不能跌太多。量縮又跌回來，表示市場對下一個趨勢沒有共識。

六個型態：
- 上漲：(a) 創高時帶量；(b) 創高後量縮、籌碼沉澱；(c) 再次爆量卻沒有創高（價量背離），要小心。
- 下跌：(a) 跌破支撐且放量，空頭明確；(b) 沒跌破支撐前不用太擔心；(c) 爆大量卻沒有再創新低，之後三天量縮，是「換手成功」的止跌訊號；若隔天又放更大量，表示還沒換手成功。

轉述者（Claude）對 EP461 的評語：比 EP464 的版本站得住，第三、四步等於內建假突破過濾；但「沒有量的訊號基本上都是假的」說得太滿、門檻從五成到五倍差距太大、「關鍵價位」要人畫線（程式只能用 N 日高低點近似）、突破仍是確認訊號不是事前訊號。

## 2. EP464：大漲與大跌前的五個訊號（轉述）

| 面向 | 逐字稿的說法 |
|---|---|
| 價格面 | 醞釀大行情的股票，盤整時每次漲多一點、跌少一點，不會一次很明顯 |
| 市場面 | 利空不跌是最大的利多；利多不漲是最大的利空 |
| 基本面 | 長線大漲要有數字佐證，獲利成長通常五成起跳；先看月營收年增率再看毛利率；成長斜率突然拉升可能是結構改變 |
| 技術面 | 沒有外力時股價在箱型內震盪；重大利多會帶量突破壓力價；跌破支撐且帶量要小心（細節併入 EP461 四步驟） |
| 籌碼面 | 管理階層申報賣股是最大利空；申報買進或庫藏股非常正面；不申報一天最多賣九張，可從券商分點看；股價大漲後辦現金增資令人費解 |

逐字稿沒有給任何命中率；是觀察清單，不是驗證過的規則。與本回測有關的只有**價格面（C2）**與**技術面（C3，經 EP461 細化）**，其餘三面（市場、基本、籌碼）不在本回測範圍。

## 4. 已知的落差與疑點（Mac 端接手時要注意）

- 回測「量縮版本為負、量未縮版本為正」與 EP461「突破後量縮較健康」的原意相反。可能是 0.7 與 T+1～T+3 窗口不是他的意思；**這個差異還沒查**，需要對照 EP461 原文怎麼描述「量縮」（相對突破日量的比例？相對均量？）。
- 檢視卡規格（C3）與回測規格不完全一致：檢視卡在 T+3 判「確認成立」（T+1～T+5 任一日跌回為失敗），回測是 T+5 才判定。若要讓兩邊一致，先決定以哪個為準。
- 文獻支持度（來自 EP464 檢視文件）：高成交量報酬溢酬（Gervais 等 2001）講的是「量放大」，不是整套四步驟；韓國市場結果相反；台股動能長期被記錄為例外，剔除極端漲跌股後才有效；「接近 52 週高點」策略在台股有獲利。四步驟整體沒有找到直接實證。
