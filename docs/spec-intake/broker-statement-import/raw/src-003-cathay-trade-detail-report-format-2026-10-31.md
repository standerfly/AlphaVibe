# SRC-003：國泰綜合證券「交易明細表」（PO 手動申請）格式紀錄

> 來源：PO 於 2026-10-31 提供的兩張截圖（信件畫面、PDF 第 2 頁）。由 Claude 轉錄**欄位
> 結構**；交易明細數值不逐筆轉錄，只保留說明格式所需的少數範例。

## 信件

- 寄件人：`國泰綜合證券 <service@edm2.cathaysec.com.tw>`（**與日對帳單不同**：日對帳單是
  `e-notification@ebill1.cathaysec.com.tw`）
- 主旨：`【國泰綜合證券】交易明細表`
- 寄達：上午 8:28（PO 手動申請後寄出）
- 內文：「附件為您 2026/05/29~2026/10/29 的交易明細。……附件已進行加密。密碼為：身分證字號
  (第一碼英文字母需大寫)」——期間由申請時指定。
- 附件：加密 PDF（與日對帳單同一組密碼）。

## PDF 內容（標題「國泰綜合證券股份有限公司(分公司) 客戶交易明細表」）

- 表頭：客戶帳號與姓名（個資）、交易日期區間（民國年，例 `115/05/29 - 115/10/29`）、頁次。
- 欄位：交易日期（民國年 `115/06/18`）、CD、股票名稱、股數、單價、手續費、交易稅、證所稅、
  融券手續費、利息、預收/留置款、價金、淨收付金額（`14,105(收)`／`11,711(付)`）、委託書號。
- CD 觀察到的值：`集買`、`集賣`、`OT買`、`OT賣`、`興買`（集＝上市、OT＝上櫃、興＝興櫃）。
- 委託書號格式：`k-06HF-00`、`k-04QS-01`、`V-00on-00`——**帶連字號、大小寫混合、末段可能
  不是 00**（同一委託分次成交，例如 `k-04QS-00` 與 `k-04QS-01` 是兩筆不同成交）。
- 有股票名稱、沒有代號（同日對帳單）。
- PDF 有「資料確認專用章」圖章。

## 與既有能力、日對帳單的比較

- 此格式就是既有 `trade_ledger_parser.py`「交易明細表」解析的格式（docstring 範例
  `115/07/22 OT賣 中美晶 50 242.50 4 36 12,125 12,085(付) k-0116-00`），PO 過去手動匯入的
  交易即來自此格式，資料庫中的委託書號是**帶連字號**的寫法。
- 日對帳單的委託書號是 `k05rg00`（**無連字號**）。兩者是同一套委託書號的不同寫法；既有防
  重複是字串完全比對，若不統一寫法，同一筆成交會被當成兩筆。
- 交易明細表只有成交，沒有庫存。
