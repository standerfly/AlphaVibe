# SRC-004：正式資料庫現況查證（2026-10-31）

> 來源：Claude 於 2026-10-31 經 claude.ai AlphaVibe 連接器唯讀查詢正式資料庫
> （`get_trade_ledger`、`get_holdings`），用於回應 code review 對委託書號格式的疑問。
> **只記錄結構性發現**；實際成交、價格、委託書號與持股屬 PO 個人財務資料，不轉錄進版控
> （下表範例的編號與數值皆為示意）。

## 1. 交易流水表已有重複成交

抽查一檔持股的交易流水，多數成交成對重複，型態如下（示意）：

| 情況 | 第一筆 | 第二筆 |
|---|---|---|
| 同一期間交易明細表匯入兩次 | 2026-07-31 匯入，委託書號 `kABCD`（無連字號、無序號） | 2026-08-31 匯入，委託書號 `k-ABCD-00` |
| 先對話回報、後交易明細表匯入 | `source_ref`＝使用者對話回報，委託書號空白 | 交易明細表匯入，有委託書號 |

- 防重複是字串完全比對，兩種寫法沒有被視為同一筆；沒有委託書號的成交完全不在防重複範圍。
- `add_sequence`（第幾次加碼）因重複而一路累加，部位控制用的加碼次數已失真。

## 2. 委託書號已知寫法

| 來源 | 寫法（示意） |
|---|---|
| 交易明細表（2026-08-31 起的解析） | `k-ABCD-00` |
| 交易明細表（2026-07-31 的舊解析） | `kABCD` |
| 日對帳單（SRC-002） | `kABCD00` |

實際編號大小寫混合（大寫、小寫、數字交錯）。

## 3. 庫存快照

- 最新快照日期 **2026-09-02**（`source_ref`＝交易紀錄自動同步），之後未再更新。
- 該快照中絕大多數股票沒有平均成本（`avg_cost` 為空）。
- 與 2026-10-29 日對帳單庫存明細相比，檔數與股數都不同；有快照中有、對帳單中沒有的股票
  （可能已賣出，或不在國泰帳戶，待 Q-013）。
