# Contract: Telegram 通知文字（011）

通道：`notify.send_telegram(text)`（純文字、不設 parse_mode）。節流：每則間隔 1.5 秒。
**通知是唯一可含標題的輸出**（FR-026、Edge Case「紀錄與外洩」）；任何通知都不得含內文、token、cookie。

## 1. 新文章（每篇一則，FR-025）

```text
📰 Substack 新文章｜{出版名稱}
{標題}
完整度：{全文｜僅預覽｜非文字}
```
- **N 類（非文字）文章**多一行固定提醒（FR-035，PO 決定 Q14；一次性，只隨該篇存入通知發出）：
  ```text
  📰 Substack 新文章｜{出版名稱}
  {標題}
  完整度：非文字
  ⚠️ 此文為非文字、內文未保存，請決定是否要處理。
  ```
  提醒句為固定文字、逐字相同，不含標題以外的文章內容、不含連結；完整度為全文／僅預覽者**不得**含此句。通知失敗補發時重送同一則（含提醒），成功後累計送達 1 次；重判（FR-033）不發通知，因此不會對同一篇再提醒。系統不自行處理 N 類文章。
- **不含文章連結**（PO 決定 A1：「不加連結」）；內容僅作者（出版名稱）、標題、完整度。這是 FR-027 明定的例外：發給 PO 本人 Telegram、只含這三項。
- **追補存入的文章同樣逐篇發送**（PO 決定 B3，FR-008／FR-025），不改發摘要；追補最多 20 則。
- `完整度`：`F`→全文、`P`→僅預覽（含 uncertain）、`N`→非文字。
- 依發布時間由舊到新送出；首次執行約 25 則。
- 失敗：同次不重試，下次執行補發，累計 3 次放棄（健檢回報）。

## 2. 摘要（本次有新文章、有告警，或有漏文提示時才發 1 則；FR-028、Edge Case）

```text
📚 Substack 匯入（{排程｜補跑｜手動｜追補}）：新增 {n} 篇（全文 {f}／僅預覽 {p}／非文字 {x}）
{可選行，x>0 時} ⚠️ 其中 {x} 篇為非文字、內文未保存，請決定是否要處理。
圖片：本次下載 {d} 張、缺圖待補 {m} 張、放棄累計 {a} 張
空間：剩餘 {free} GB；substack.db {db} MB；圖片 {img} MB
{可選行} 提示：{出版名稱} 本次 feed 的 {k} 篇皆為新文，兩次輪詢之間可能有漏文（只提示，不補救）
{可選行} 通知：{q} 篇尚未通知成功，下次執行補發
```
空間數字只報現況，不含任何「異常／不足」判定字眼（FR-028）。摘要在「本次有新文章、有告警或有漏文提示」時發（FR-025，PO 決定 B4），因此也包含**只有告警、沒有新文章**與**追補**的執行。

## 3. 告警（固定文字，不含標題；FR-005、FR-032）

| 代碼 | 觸發 | 文字 |
|---|---|---|
| `blocked` | 403／429／HTML 挑戰頁（任何策略皆立即） | `⚠️ Substack 匯入：{出版名稱} 被站方擋下（{403｜429｜非 feed 回應}），本次已停止該作者、不重試，下次排程再試。` |
| `fetch_failed` | 其他失敗；`every_failure`：每次；`consecutive_3`：連續第 3 次 | `⚠️ Substack 匯入：{出版名稱} 抓取失敗（{逾時｜網路錯誤｜無法解析｜HTTP {碼}｜robots 不允許}，連續 {c} 次），下次排程再試。` |
| `disk` | 磁碟寫入失敗 | `⚠️ Substack 匯入：寫入失敗（可能是硬碟空間不足），本次已中止，已存文章不受影響。剩餘空間 {free} GB。` |
| `config_invalid` | 設定檔不存在或驗證失敗 | `⚠️ Substack 匯入：設定檔無法使用（{不存在｜格式錯誤}），本次未發出任何請求。請在對話中請 Claude 檢查設定。` |

- 出版名稱來自 PO 自己的設定檔，不是文章內容。
- **每則告警末尾都加一行空間現況**（FR-028「有事件的通知附帶空間現況」）：`空間：剩餘 {free} GB；substack.db {db} MB；圖片 {img} MB`；取不到時寫 `空間：無法取得`；只報現況數字，不含判定字眼。（`disk` 告警原本就含剩餘空間，補上其餘兩項以統一格式。）
- `blocked` 的觸發包含「站方回傳 HTML 挑戰頁」（PO 決定 B2，視同 403／429），文字中的原因寫「非 feed 回應」。
- 錯誤原因只用上表代碼對應的固定詞，不嵌入例外原文或回應內容。

## 4. 不發通知的情況

- 所有作者都沒有新文章且沒有任何告警（US1-AS4）。
- 作者因最小間隔被跳過（FR-004）。
- `--reclassify`（重判）：不發通知（FR-033）。
- `--dry-run`、`--status`、`deferred`／`already_done` 的排程執行。
- 手動轉寫（結果只在 stdout 與 `transcription_trial`）。
