# Error Handling Matrix: AutoCharge FreeCharge

**Last Updated:** 2026-05-12
**Status:** Complete

|--------------|------------------------------|------------------------------------|---------------|--------------|-------------------------------|--------|

| Retail 5xx, network error, connection refused, temporary unavailable, or parse failure | Order created with new `EligibilityPending`; payment and invoice blocked. | 203 Checkout still returns existing success contract to CPO/LXM; system records pending status. | Retry Retail eligibility every 5 minutes against the existing order; stop after 12 attempts or 60 minutes. | AutoCharge operations | Pending order, order age, and scheduler/job log evidence linked by `order_id` and `request_id`. | SRC-001, SRC-002, SRC-003, SRC-005 |
| Retail 4xx caused by missing or invalid vehicle UUID | Order created with new `EligibilityPending`; payment and invoice blocked. It is not treated as not eligible and does not continue to normal payment. | Alert for recovery while preserving existing 203 success response contract to CPO/LXM. | Manual investigation or corrected retry path. | AutoCharge operations with TPM/Retail support if needed | Decision record, pending order evidence, and Retail response evidence. | SRC-005 |
| Missing successful 202 ValidateCar log, missing 202 `requestTime`, unparsable 202 `requestTime`, or vehicle UUID cannot be resolved before Retail call | Order created with new `EligibilityPending`; payment and invoice blocked. AutoCharge does not call Retail and does not mark order as FreeCharge. | 203 Checkout still returns existing success contract to CPO/LXM; system records pending status. | Retry or reconcile later using approved pending policy. | AutoCharge operations | Pending order and missing-input evidence. | SRC-001, SRC-004, SRC-005 |
| Duplicate 203 Checkout request | Existing order remains authoritative; no duplicate order created. | Preserve current response code `EC215`. | Do not repeat Retail call. | AutoCharge service owner | Duplicate key evidence by `requestId` or `carId + startTime + endTime`. | SRC-001, SRC-002, SRC-005 |
| Negative 203 Checkout amount | Request is invalid and no order should be created. | Existing DTO validation rejects amount below zero. | Return current validation error behavior. | AutoCharge service owner | Request validation evidence. | SRC-002 |
| FreeCharge order enters payment flow | Payment leakage risk. | Raise alert, stop payment if possible, mark reconciliation required. | Manual reconciliation and guard correction. | AutoCharge operations | Alert and reconciliation record. | SRC-001, SRC-002 |
| FreeCharge order enters invoice issuance | Invoice leakage risk. | Raise alert, stop invoice if possible, mark reconciliation required. | Manual reconciliation and guard correction. | AutoCharge operations with Finance/Tax if needed | Alert and reconciliation record. | SRC-001, SRC-002, SRC-003 |
| Pending order enters payment flow | Payment leakage risk before eligibility resolved. | Raise alert, stop payment if possible, mark reconciliation required. | Manual reconciliation and guard correction. | AutoCharge operations | Alert and reconciliation record. | SRC-001, SRC-002 |
| Pending order enters invoice issuance | Invoice leakage risk before eligibility resolved. | Raise alert, stop invoice if possible, mark reconciliation required. | Manual reconciliation and guard correction. | AutoCharge operations with Finance/Tax if needed | Alert and reconciliation record. | SRC-001, SRC-002, SRC-003 |
| Pending order remains older than 30 minutes | Stuck pending warning. | Alert warning for operator visibility. | Continue retry until 12 attempts or 60 minutes unless manually resolved earlier. | AutoCharge operations | Pending age and retry evidence. | SRC-005 |
| Pending order remains older than 60 minutes or reaches 12 failed retry attempts | Stuck pending requiring manual recovery. | Manual recovery alert. | Manual investigation, corrected retry path, or reconciliation. | AutoCharge operations | Pending age, retry count or job evidence, and recovery record. | SRC-005 |
